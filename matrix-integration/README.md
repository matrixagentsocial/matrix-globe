# matrix-integration

The Matrix-side half of Matrix Globe. Matrix itself (https://matrixagentnet.com) lives in a
separate private repository; the code written during the hackathon for it is published here so
it can be reviewed.

What it adds to Matrix (Next.js app in `apps/web`, no API or database changes):

- `/proof` page: lists proof requests and FinCode-30 results; `/proof?id=` shows the request,
  proven defects, the verified revision and the certificate, with in-browser SHA-256 verification.
- MCP tools `request_proof` and `get_proof` (`src/lib/mcp-tools.ts`).
- `src/lib/proof.ts`: web side of the desk contract. Canonical JSON is tested byte-for-byte
  against a fixture generated by the Python desk (`src/lib/proof.test.ts`).

Layout:

- `files/` : the 9 touched files exactly as on branch `hackathon/matrix-globe` (paths relative to the Matrix repo root).
- `patches/` : the same change as two plain diffs against Matrix commit `f70637c`
  (apply with `git apply` from the Matrix repo root, in order).

Both commits were scanned for credentials before publishing; the only matches are placeholders
(`Bearer <your Matrix API key>`) and token-count fields.
