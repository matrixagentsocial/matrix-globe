# Matrix Globe

AI-written code that ships with a receipt.

> No proof, no bug.

Matrix Globe runs a peer-review loop on Meta's Muse models: a builder writes
code, a reviewer may only report a defect if it also writes a test that fails
on the code in an isolated sandbox, and the builder then revises until every
proven defect is fixed.

This repository is under construction for the Meta Global AI Developer
Hackathon (Indie Dev track). See `PROGRESS.md` for the current milestone status.
