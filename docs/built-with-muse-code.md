# Built with Muse Code

Two agents built this repository during the hackathon, with one human owner
setting the goals. This page says which agent wrote which part. It was put
together from the Muse Code session logs (`muse exec --json` event streams:
every `write_file` / `edit_file` tool result and the `run.usage` record) and
from the git history.

- **Muse Code** (`muse-wonder-1.0`, effort `high`, run headless with
  `muse exec --json --disable-reminders`) built the product, one milestone at
  a time: the loop, the sandboxes, the benchmark, the mutants, the PR packages
  and the desk.
- **Claude Code** supervised. It wrote each session's brief, reviewed every
  diff, ran the tests, fixed what was broken and ran the benchmarks. It also
  wrote the parts listed below. The briefs and review notes are in
  [`PROGRESS.md`](../PROGRESS.md) under "Review notes".

## Written by Claude Code

- **Reviews and fixes after every Muse session.** For example: anchoring the
  ledger path to the repo root; building the strict JSON schemas with
  `additionalProperties: false`; the Docker sandbox report path, mounts and
  kill-on-timeout; CI with live Docker checks; `tzdata` for Windows.
- **The open-weights stack** (branch `open-weights`): routing `meta-models/*`
  to Baseten with its own spend cap; the `C_open`, `E_open` and `D_open`
  conditions; the `DESK_STACK=open` desk mode; the fix that passes the loop's
  model to every role call.
- **The GitHub Actions sandbox** (`proof/sandbox/gha.py`, `gha_job.py`, the
  `sandbox` workflow) that lets the desk run on the owner's PC with no
  secrets in GitHub, and the hidden scheduled-task launcher.
- **The static proof viewer** in `site/` (GitHub Pages) and its hash check in
  the browser.
- **The final-run drivers and resume.** The final rows and bundles themselves
  are the output of Muse-built code.
- **`bench/classify_unconfirmed.py`**: the manual classification of the 190
  UNCONFIRMED claims.
- **This README, this page** and the Matrix-side web `/proof` page and MCP
  tools (in the Matrix repository, branch `hackathon/matrix-globe`).
